# KALLISTIS — Pacote para Google Antigravity

## Uso

1. Extraia este pacote em uma pasta limpa.
2. Abra a pasta no Google Antigravity.
3. Leia e execute integralmente:
   `00_COMECE_AQUI/PROMPT_ANTIGRAVITY_EDICAO_DEFINITIVA_KALLISTIS_v1.1.md`
4. Use somente:
   `01_FONTE_UNICA/KALLISTIS_LIVRO_BASICO_BASE_PARA_REVISAO.docx`
5. A auditoria é referência técnica; não é fonte de cânone.
6. O Antigravity deve criar `source/`, `work/` e `output/`.
7. A saída esperada é:
   - `output/KALLISTIS_LIVRO_BASICO_EDICAO_DEFINITIVA_v1.1.docx`
   - `output/KALLISTIS_LIVRO_BASICO_EDICAO_DEFINITIVA_v1.1.pdf`
