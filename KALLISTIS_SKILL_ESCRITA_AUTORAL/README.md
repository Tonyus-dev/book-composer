# Skill de Escrita Autoral — KALLISTIS

Pacote local para agentes do Google Antigravity.

## Instalação

Copie:

```text
.agents/skills/kallistis-human-prose/
```

para a raiz do workspace do livro.

## Arquivos

- `SKILL.md` — regras principais;
- `references/VOICE_GUIDE.md` — voz de KALLISTIS;
- `references/ANTI_AI_PATTERNS.md` — padrões artificiais;
- `references/REVISION_CHECKLIST.md` — checklist;
- `references/ANTIGRAVITY_INTEGRATION.md` — integração;
- `scripts/style_lint.py` — linter heurístico;
- `scripts/compare_style_metrics.py` — comparação entre fonte e revisão.

## Observação

Nenhuma Skill garante que um texto “passe” por detectores. Detectores de IA são inconsistentes. O objetivo deste pacote é qualidade editorial, especificidade, ritmo e fidelidade autoral.
